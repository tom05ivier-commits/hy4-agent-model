# hy4-agent-model

Data agen dan model AI **hy4-flash-free** milik IT Agenty / Tomi vier.

Repositori ini berisi:
- konfigurasi model hy4 (`hy4/model.json`),
- agent OpenCode (`hy4/agents/`),
- command OpenCode (`hy4/commands/`),
- pengetahuan platform engineering, Doctor CLI, strategi, dan privasi,
- manajer `manage_hy4.sh` untuk memasang ulang semuanya.

Semua file telah disanitasi: tidak ada email, WhatsApp, tanda tangan asli,
atau kata sandi. Lisensi: **Tom05ivier-commits-1.0**.

## Pakai

```bash
./manage_hy4.sh status
./manage_hy4.sh install --no-cli
./run_platform.sh context
doctor version
```
